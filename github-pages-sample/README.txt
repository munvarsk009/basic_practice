MY FIRST GITHUB PAGES WEBSITE

Files:
- index.html: website content
- style.css: website design
- script.js: button interaction

UPLOAD WITHOUT COMMANDS:
1. Open your GitHub repository.
2. Click Add file > Upload files.
3. Upload index.html, style.css and script.js (or upload all files).
4. Click Commit changes.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose main and /(root), then click Save.
8. Wait a few minutes. Your site URL will be:
   https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

Keep index.html in the repository's root folder.
